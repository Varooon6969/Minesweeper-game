A simple Minesweeper game, implementing Reinforcement Learning
To run the program use the Python 3.12 IDE, IDLE
A simple but effective project prepared for Deep Learning Of Gaming Technology
MinesweeperGUI file consists of a fully scaled Reinforcement Learning AI model that uses Q-Learning methods to find optimal solutions to solve the Minesweeper game everytime, the other 2 python files consists of a base prototype model that uses Q-Learning to solve the game
